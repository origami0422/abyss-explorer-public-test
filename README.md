# 深淵的探索者｜Windows 公開測試版

單人文字跑團遊戲，以自然語言與 AI 主持人遊玩。此為非商業測試版，規則效果尚未全部自動結算。

從 [Releases](../../releases) 下載 `public-test-windows-x64.zip`，全部解壓縮後執行「啟動遊戲.cmd」。需要 Windows 64 位元、網路及本人可用的模型帳號；首次登入請依官方流程授權。詳見壓縮包的「測試說明.txt」。
